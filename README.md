# React Profile Page - TN Skills

A modern, responsive profile page built with React and Bootstrap Icons as part of the TN Skills frontend development task.

## 🎯 Project Overview

This project demonstrates modern React development practices with interactive user interface elements. It showcases essential front-end skills including component design, state management, and responsive layouts.

## ✨ Features

- **Hero Section** - Eye-catching landing section with welcoming introduction
- **Favorite Activities** - Display of 4 favorite activities with Bootstrap Icons
- **Interactive Profile** - Profile card with dynamic like counter functionality
- **Text Display** - Input box that captures and displays text after button submission
- **Responsive Design** - Mobile-first approach that looks great on all devices
- **React Components** - Modular, reusable component architecture

## 🛠 Tech Stack

- **React** (v19.2.8) - UI framework
- **Bootstrap Icons** (v1.13.1) - Icon library
- **React Scripts** (v5.0.1) - Build and development tools

## 📦 Installation

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Setup Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rishirk011/React-profile-page-tn-skills.git
   cd React-profile-page-tn-skills
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```
   The app will open automatically at `http://localhost:3000`

## 🚀 Available Scripts
